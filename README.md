# nowardethan.github.io

Portfólio de **André Ramos de Oliveira** — desenvolvedor.

Site estático, sem build: HTML, CSS e um arquivo de JavaScript. Publicado pelo GitHub Pages
a partir da branch `main`, na raiz.

- **No ar:** https://nowardethan.github.io
- **Ecossistema Aura:** https://aura-ecossistema.web.app

## Como mexer

Abra o `index.html` no navegador. Não há dependências nem passo de build.

| Arquivo | O que tem dentro |
|---|---|
| `index.html` | Conteúdo e estrutura das seções |
| `styles.css` | Tema claro e escuro, layout e responsividade |
| `script.js` | Alternador de tema, entrada suave e a lista de projetos |

A lista de projetos é buscada ao vivo na API pública do GitHub. Se a API não responder,
a página mostra a lista de reserva que está dentro do `script.js`.
