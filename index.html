Desktop com Electron

Processo principal e renderer separados com IPC tipado e contexto isolado, janela sem moldura com controles próprios, terminal com PTY real, atualização automática e assinatura de binários para o Windows não barrar a instalação.

  • Electron
  • IPC seguro
  • node-pty
  • Code signing
  • Auto-update

Interface em React

Componentização pensada para reuso, painéis redimensionáveis e colapsáveis, editor Monaco integrado com tema próprio, virtualização de listas grandes e animação só em transform e opacity, respeitando quem prefere menos movimento.

  • React
  • TypeScript
  • Vite
  • Monaco
  • Acessibilidade

Orquestração de modelos

Pipeline multi-modelo com memória persistente, política dinâmica e validação de comportamento: um modelo grande dá a voz, modelos menores cuidam das partes especializadas, e o núcleo decide quem responde o quê. Inclui laço de agente com ferramentas e aprovação do usuário.

  • LLM
  • Agentes
  • Memória
  • Node
  • Docker

Android nativo

Aplicativo em Kotlin com Jetpack Compose, publicado com distribuição própria de APK e canal de atualização, além de um app em React Native com Expo consumindo a mesma API.

  • Kotlin
  • Compose
  • React Native
  • Expo

Backend e infraestrutura

API HTTP em produção para o aplicativo móvel, com chat, transcrição, visão e cobrança, empacotada em Docker e publicada no Railway. Autenticação e regras de acesso no Firebase, hospedagem e distribuição de releases.

  • Node
  • Docker
  • Railway
  • Firebase
  • CI

Comunicação em tempo real

Voz ponto a ponto no desktop, salas e canais, presença e sincronização de estado entre participantes, com o cuidado de privacidade que uma conversa exige.

  • WebRTC
  • P2P
  • Firebase
  • Electron

Aura, o ecossistema

Quatro aplicativos que conversam entre si: uma IDE com agente, uma plataforma de comunidades por voz, uma assistente com memória e a loja que instala e atualiza tudo.

Luna IDE

Em desenvolvimento

Ambiente de desenvolvimento com a Luna dentro: ela lê o projeto, escreve código, roda comandos e pede aprovação antes de agir. Editor Monaco, terminal com shell real e múltiplas abas, busca com ripgrep, painel de Git com commit escrito pela IA e um cadeado de privacidade que mostra exatamente o que sai da máquina.

  • Electron
  • React
  • TypeScript
  • Monaco
  • PTY
